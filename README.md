# 🎮 Rekomendasi Game untuk Kamu! 🎮

Bosen main game yang itu-itu aja? Lagi cari game baru yang sesuai sama *mood* kamu saat ini? Tenang, proyek ini siap bantuin kamu!

## 🔥 Apa Sih Ini?

Ini adalah sebuah sistem rekomendasi game yang akan membantumu menemukan game yang paling pas untuk dimainkan, berdasarkan *mood* dan genre yang kamu inginkan.

## 🤔 Cara Pakainya Gimana?

Gampang banget! Cukup kasih tau kami:

*   **Mood kamu saat ini:** Lagi pengen petualangan epik, santai-santai di pedesaan, adu tembak yang menegangkan, atau pusing-pusing mikirin teka-teki?
*   **Genre favoritmu:** Suka RPG dengan cerita mendalam, simulasi yang bikin rileks, FPS yang penuh aksi, atau game puzzle yang mengasah otak?

Nanti, sistem ini akan memberikan rekomendasi game yang paling cocok buat kamu!

## 🚀 Contoh Penggunaan

Misalnya, kamu lagi pengen **berpetualang** dan suka game **RPG**, maka sistem akan merekomendasikan:

*   The Witcher 3: Wild Hunt
*   The Elder Scrolls V: Skyrim

Atau, kalau kamu lagi pengen **santai** dan suka game **simulasi**, maka rekomendasinya adalah:

*   Stardew Valley
*   Animal Crossing: New Horizons
